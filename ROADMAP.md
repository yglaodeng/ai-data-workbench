# Roadmap

## Near term

- Add more synthetic examples for multi-sheet joins and traceable exports.
- Document common natural-language goals with the exact generated plan.
- Improve first-run diagnostics and error messages for unsupported input shapes.

## Later

- Evaluate additional file formats through isolated, reproducible tests.
- Expand provenance reporting for multi-step transformations.
- Add optional local model adapters without requiring a cloud account.

## Out of scope for the public prototype

- Reading production databases or credentials.
- Overwriting original workbooks.
- Autonomous business decisions or unreviewed execution.
- Claims of universal natural-language understanding without requirement-level evidence.
